# Codex Weekly Overlay Implementation Plan

> **For agentic workers:** Use superpowers:test-driven-development for core behavior and superpowers:requesting-code-review before delivery. 用户已批准在当前会话实施，按独立文件职责执行并复核。

**Goal:** 交付无需再次登录、带可穿透悬浮环与历史曲线的 Windows x64 软件。

**Architecture:** `crates/limit-core` 负责协议解析、SQLite 与设置；`src-tauri` 负责 Windows 窗口、托盘和采集调度；`scripts/wsl_bridge.py` 负责读取当前 WSL Codex；`src` 负责网页界面。核心库独立于桌面运行时，允许在 WSL 原生测试，再交叉编译 Windows 程序。

**Tech Stack:** Rust、Tauri 2、React、TypeScript、Vite、SQLite/rusqlite、Python 3 标准库、SVG。

## 1. 额度与持久化

- [ ] 建立 Cargo workspace，版本统一 0.1.0；核心代码分为 `quota.rs`、`store.rs`、`settings.rs`。
- [ ] 先写 Rust 测试：primary/secondary 10080 分钟窗口、新旧响应、其他桶干扰、缺失窗口及非法百分比；先运行确认失败，再实现解析。
- [ ] 先写真实 SQLite 内存库测试：按账号保存采样、按时间范围读取、重置分组、保留 90 天与设置校验；先失败再实现。
- [ ] 验证命令：`cargo test -p limit-core`，要求无失败；`cargo clippy -p limit-core -- -D warnings`。

## 2. WSL 只读桥接

- [ ] `scripts/test_wsl_bridge.py` 使用临时可控 app-server 进程验证初始化顺序、通知交错、JSON 错误、服务错误、超时与结束后回收。
- [ ] `scripts/wsl_bridge.py` 实现现有可用 Codex 定位、JSONL 读取和明确超时；不加载/输出凭证，不调用 thread/turn。
- [ ] 验证命令：`python3 -m unittest discover -s scripts -p 'test_*.py'`；`python3 scripts/wsl_bridge.py` 返回真实额度但不输出身份或令牌。

## 3. Windows 运行时

- [ ] `src-tauri/src/collector.rs` 用统一刷新通知与定时循环采样，限制重入，Windows 启动 WSL 隐藏控制台，超时回收；失败保留最近有效值。
- [ ] `src-tauri/src/windows.rs` 创建/销毁主窗口、透明置顶悬浮窗、拖动及锁定穿透；位置恢复检查显示器边界。
- [ ] `src-tauri/src/tray.rs` 实现托盘点击、右键菜单、状态同步与退出。
- [ ] `src-tauri/src/commands.rs` 提供快照、历史、设置、刷新、窗口控制等最小 IPC；仅允许本地前端调用。
- [ ] 使用 Tauri 官方配置，静态打包网页资源和内嵌桥接脚本；持久化错误必须反馈到 UI。
- [ ] 验证命令：`cargo check -p codex-weekly-overlay --target x86_64-pc-windows-gnu`。

## 4. 界面

- [ ] `src/lib/types.ts` 定义共享 IPC 数据类型；`src/lib/api.ts` 封装 Tauri 调用和显式浏览器演示模式。
- [ ] `src/components/QuotaRing.tsx` 复用同一个 SVG 圆环，支持 overlay 与 dashboard 尺寸，不编写两份额度展示逻辑。
- [ ] `src/components/HistoryChart.tsx` 实现可访问的 SVG 历史曲线、分段、悬停详情和空状态；不伪造生产数据。
- [ ] `src/views/Overlay.tsx`、`src/views/Dashboard.tsx`、`src/styles.css` 实现浅绿视觉、可操作的设置及真实连接状态。
- [ ] 验证命令：`npm run check`、`npm run build`；浏览器分别验证 `?view=overlay&demo=1` 和 `?demo=1`。
